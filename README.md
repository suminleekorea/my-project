# Sumin Lee

Personal profile page for Sumin Lee, focused on AI-enabled product marketing,
customer success, pre-sales, and marketing analytics.

## Profile Focus

- Generative AI workflow design for business research, messaging, and reporting
- SQL, Python, R, Power BI, Tableau, CRM analytics, and campaign optimization
- Product marketing, customer growth, account strategy, and sales enablement
- Target markets: Singapore, Korea, and Dubai

## Local Development

```bash
npm run dev
npm run build
npm run lint
```

The app uses Next.js 15, the App Router, TypeScript, and Tailwind CSS v4.
